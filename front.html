// 04 — FAQ

Questions,
answered.

01How can a 20B model feel this fast?+

It runs on Groq's LPU inference hardware, which streams tokens far faster than typical GPU-hosted endpoints at this size.

02Does turning off web search cost credits?+

No. Disabling search, or the search backend being unreachable, never deducts credits — only a genuine verification failure does.

03Can I run this on my own hardware?+

Yes — it's a plain Flask app with CORS enabled. Point the frontend's API URL at wherever you deploy it.

04What happens below 700 credits?+

"Careful mode" turns on: the system prompt asks the model to lean harder on web context and flag anything it isn't sure of.
